
# Stelangana Foods

## Description

Stelangana Foods is a web-based platform designed to showcase and sell authentic Telangana traditional food products such as snacks, sweets, and accompaniments.

The project currently focuses on building a visually appealing and user-friendly frontend interface that allows users to browse products, add items to the cart, and view order totals dynamically.

The backend system for customer authentication, payment processing, and order management will be integrated in the upcoming development phase.


## Features

- Product catalog for traditional Telangana foods

- Categorized items (Snacks, Sweets, Accompaniments)

- Dynamic shopping cart functionality

- Add-to-cart and remove-from-cart system

- Automatic total price calculation

- Responsive design for mobile, tablet, and desktop

- Clean and intuitive navigation interface

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/stelangana-foods.git
```

Navigate to the project folder:

```bash
cd stelangana-foods
```
Run the project by opening the index.html file in your browser.
## Usage

**1.** Open the website in your browser.

**2.** Browse the available food categories.

**3.** Add items to the cart.

**4.** View the cart to see selected products and total cost.

Future versions will allow users to complete orders and make payments.
